Fair task assignment with a round-robin workflow

n8nGoogle SheetsGmail

In a content team, scripts come in all day and need to reach an editor quickly. Deciding by hand who gets what is slower than it sounds — and over time it can start to feel uneven, with some editors getting more work than others.

I built the Editor Distribution System to take that decision off my plate and make it fair by design.

Why round-robin?

Round-robin is the simplest fair system there is: tasks go to each person in turn, then the cycle starts again. Nobody has to remember who's next, and everyone gets an even share.

How it works

  1. New scripts land in a Google Sheet that acts as the queue.
  2. n8n picks up each new script and checks who received the last assignment.
  3. It assigns the script to the next editor in the rotation and records the assignment back in the sheet.
  4. Each editor gets an email with their new task, so nothing depends on them checking a sheet.

What made it work

  • One source of truth. The sheet records every assignment, so it's easy to see who has what.
  • Notifications, not lookups. Emailing editors directly means work starts sooner.
  • Simple rules. A rotation everyone understands is easier to trust than a clever one nobody can explain.

The takeaway

Not every automation needs AI. Sometimes the biggest win is taking a small, repeated decision and making it automatic, consistent, and fair.
